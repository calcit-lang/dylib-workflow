# 发布 0.0.5 / Release 0.0.5

## 中文

- 发布基于 `calcit_native_ffi 0.1.2` 的 native 模块模板。
- 同步 Cargo crate 与 `deps.cirru` 模块版本为 0.0.5，修正此前模块元数据仍停留在 0.0.3 的偏差。
- 保持 buffer protocol v1、公开 symbol、Calcit 0.13.57 最低版本和 `path-exists?` 行为不变。

## English

- Release the native-module template backed by `calcit_native_ffi 0.1.2`.
- Synchronize the Cargo crate and `deps.cirru` module versions at 0.0.5, correcting module metadata that still reported 0.0.3.
- Preserve buffer protocol v1, public symbols, the Calcit 0.13.57 minimum, and `path-exists?` behavior.
