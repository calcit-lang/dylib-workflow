# Template release policy / 模板发布策略

## 中文

- 明确 dylib-workflow 是复制或 fork 使用的模板仓库，不是独立发版模块。
- `deps.cirru :version` 仅保留为项目元数据；维护合并后不递增版本、不打版本 tag、不创建 GitHub Release。
- 同步 README 中 `calcit_native_ffi` 的当前版本为 0.1.3。

## English

- Clarify that dylib-workflow is a template consumed by copying or forking, not an independently released module.
- Keep `deps.cirru :version` as project metadata only; maintenance merges do not bump it, create version tags, or publish GitHub releases.
- Align the README's current `calcit_native_ffi` version with 0.1.3.
