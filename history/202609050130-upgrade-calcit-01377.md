# Upgrade the native dylib template to Calcit 0.13.77

- Raise the declared Calcit baseline from 0.13.64 to 0.13.77 without changing the template metadata version.
- Use the exact maintained `setup-calcit@v1.4.0` release tag, rather than a raw commit SHA or moving major-version tag, so CI no longer requests the retired `cr` release asset while the workflow remains reproducible and maintainable.
- Verify the installed compiler against `deps.cirru` immediately after tool installation, before strict dependency resolution and every existing Rust, export, Snapshot, type-quality, and runtime gate.
- Preserve the shared `calcit_native_ffi` C-safe buffer ownership and Cirru EDN transport contract.

## 中文

- 将声明的 Calcit 基线从 0.13.64 升级到 0.13.77，不修改模板元数据版本。
- CI 使用精确的 `setup-calcit@v1.4.0` 发布标签，而非 raw commit SHA 或可移动的主版本标签，避免继续请求已停用的 `cr` release asset，同时保持可复现和可维护。
- 工具安装后立即核对实际编译器与 `deps.cirru` 一致，再执行 strict 依赖解析以及全部现有 Rust、导出符号、Snapshot、类型质量与运行门禁。
- 保持共享 `calcit_native_ffi` 的 C-safe buffer ownership 与 Cirru EDN transport 契约不变。
