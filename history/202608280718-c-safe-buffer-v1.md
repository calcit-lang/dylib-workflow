# C-safe buffer v1 workflow / C-safe buffer v1 工作流

## 中文

- 将示例从 Rust `Vec<Edn>` dylib entry point 迁移到 C-safe buffer protocol v1。
- 改用 `cdylib`，删除 build/version probes 和 Rust ABI exports。
- 升级 Calcit 到 0.13.57，CI 增加 strict clippy、Rust tests、symbol audit、caps 和真实 Calcit 调用。

## English

- Migrate the example from a Rust `Vec<Edn>` dylib entry point to C-safe buffer protocol v1.
- Switch to `cdylib` and remove build/version probes and Rust ABI exports.
- Upgrade to Calcit 0.13.57 and add strict clippy, Rust tests, symbol auditing, caps, and a real Calcit call to CI.
